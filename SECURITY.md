# Security Policy

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or discussion.

Report them privately through GitHub instead: open the [Security tab](https://github.com/7ovr/shadcn-vite-starter/security) and choose **Report a vulnerability**. Include what you found, the steps to reproduce it and the impact you expect.

You will get a reply within a few days. Once the problem is confirmed, a fix is released as soon as possible and you are credited in the advisory, unless you prefer not to be.

## Supported versions

Only the latest commit on `master` is supported. The starter is a template you copy, so after you start a project from it, keep your own dependencies up to date.

## Scope

This covers the code in this repository. Problems in a dependency, such as React, Vite or a TanStack package, belong with that project, though a note here is welcome if the starter's setup makes one worse.
